# Library Management System – Frontend

A web-based Library Management System frontend built using HTML5 and CSS3. The project provides separate dashboard interfaces for administrators and library members, focusing on a clean layout and easy navigation.

## Features

### Admin Dashboard
- Dashboard overview of library activities.
- Display total books and registered members.
- Overview of borrowed and overdue books.
- Recent borrowing activity.
- Book availability statistics.
- Add New Book form interface.
- Outstanding fines overview.

### Member Dashboard
- Personalized member dashboard.
- Overview of currently borrowed books.
- Display book due dates.
- Borrowing history.
- Membership information.
- Book catalogue interface.
- Search interface for books.
- Book availability indicators.

## Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/vavi-hub/Library-Frontend.git
```

**2. Navigate to the project directory**

```bash
cd Library-Frontend
```

**3. Run the project**

Open either HTML file directly in your browser.

For the Admin Dashboard:

```bash
xdg-open admin.html
```

For the Member Dashboard:

```bash
xdg-open member.html
```

Alternatively, use the Live Server extension in Visual Studio Code.

## Project Interfaces

The project provides two separate interfaces:

- **Admin Dashboard:** Designed for library administration and monitoring.
- **Member Dashboard:** Designed for members to view their library-related information.
